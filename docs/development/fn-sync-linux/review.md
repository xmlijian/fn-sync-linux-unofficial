# 按需同步稳定性审查

审查范围：调度、缓存锁、外部控制、文件管理器状态、停止确认。

已处理阻断项：
- O_TRUNC 与非零 resize 统一经文件锁，非零 resize 先恢复旧内容。
- create/open/release 使用一致打开计数；释放前在 gate 中检查打开句柄。
- 上传锁等待失败返回错误，避免 fsync 假成功。
- 冲突检测 ls/download 失败立即停止上传，不能在未知远端状态下覆盖。
- pin 会排队下载，取消保留后才允许释放。
- 上传恢复成功清除错误；取消周期读取 pins.json，守护进程为唯一写入者。
- 目录查询独立于传输；读请求等待同一文件下载时异步等待，最多 128 个待处理读、4 个实际下载。
- 控制 socket 0600，帧 8KiB、连接 16、耗时控制操作 4；状态请求不占控制操作配额。

验证：90 项默认测试通过（10 项需外部条件的测试默认忽略）；两项显式启用的假 NAS 实际 FUSE 测试通过，覆盖读写、缓存恢复、冲突保留、慢远端目录访问与停止。Python 脚本编译检查通过。新增真实 Unix socket 集成测试验证下载/释放/保留和拒绝脏文件、路径越界、文件锁竞争；新增非零 resize 前缀保留与队列隔离测试。

限制：Nautilus 扩展通过异步 500ms 状态轮询触发 invalidate_extension_info，未在 GUI 中视觉验收。UOS DDE、麒麟 Caja/Peony 等非 Nautilus 文件管理器尚无专用列适配；CLI 可用。当前 Ubuntu amd64 链接依赖未满足旧麒麟/UOS，不将 gzip 压缩等同于运行库兼容。下载仍为整文件缓存（首次读取等待完整文件），上传仍整文件缓冲，后续可独立引入范围读/流式上传。
