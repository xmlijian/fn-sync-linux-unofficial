# v0.2.3

首个 GitHub 发布版本，提供新系统版与信创版两类安装包。

## 下载

| 目标系统 | 文件 |
|---|---|
| Ubuntu 22.04+ / Debian 12+ / Fedora 38+（amd64） | `fn-sync-client_0.2.3-20_amd64.deb` |
| 通用 x86_64 | `fn-sync-client-0.2.3-x86_64.AppImage` |
| 麒麟 V10 / UOS 20（x86_64） | `fn-sync-client_0.2.3-web40_amd64.deb` |
| 麒麟 V10 / UOS 20（aarch64） | `fn-sync-client_0.2.3-web40_arm64.deb` |
| 信创版 x86_64 便携包 | `fn-sync-client-0.2.3-web40-x86_64.AppImage` |
| 信创版 aarch64 便携包 | `fn-sync-client-0.2.3-web40-aarch64.AppImage` |

校验：`sha256sum -c SHA256SUMS.txt`

## 安装

```bash
# Debian / Ubuntu / 麒麟 / UOS
sudo dpkg -i <deb 文件>
sudo apt -f install

# AppImage
chmod +x <AppImage 文件>
./<AppImage 文件>
```

## 变更

- 按需同步：空目录校验、崩溃后死挂载自动回收、暂停/取消传输
- NAS 会话失效后的自动重连（tokenLogin → authToken）
- 文件管理器角标与桌面状态面板
- 信创版：Peony/DDE 文件管理器插件，x86_64 与 aarch64 构建
