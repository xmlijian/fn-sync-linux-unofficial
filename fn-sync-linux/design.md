# 按需同步稳定性设计

授权范围为此前排查方案：守护进程统一控制缓存，元数据与传输分离，状态通过本地 IPC 查询并主动刷新，停止后确认挂载移除。保持 gzip Debian 包，不宣称当前 Ubuntu 构建兼容全部麒麟/UOS。

每个任务提供仅当前用户可访问的 Unix socket，限制请求大小、并发和执行时间。CLI 不再直接修改缓存，状态列异步获取同一状态源。下载仍采用整文件缓存语义，但与目录查询隔离，重复下载等待同一文件锁。释放使用同一锁并拒绝打开、脏、保留、传输中的文件。缓存路径锁不随缓存淘汰删除，避免两把锁保护同一路径。

文件管理器通知不作为状态真相。状态快照含真实字节进度和最近错误，Nautilus 定时异步刷新已显示条目。内核失效通知独立于 touch，避免通知串行阻塞。停止请求取消网络等待，确认内核挂载移除后才允许新挂载。
