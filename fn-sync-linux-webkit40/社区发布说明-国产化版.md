# 飞牛同步 Linux 客户端 v0.2.3 —— 国产化系统适配版（麒麟 V10 SP1 / UOS 20）

## 这是什么

官方"飞牛同步"只提供 Windows 和 macOS 客户端。这个版本是基于官方 0.2.3 协议逆向实现的
Linux 第三方客户端，**专门适配只有 `libwebkit2gtk-4.0`（libsoup2）运行库的国产化系统**：

- 麒麟 V10 SP1（aarch64）：UKUI 桌面 + Peony 文件管理器
- UOS 20 专业版（x86_64）：DDE 桌面 + DDE 文件管理器

界面直接复用官方前端（自绘标题栏、中/英/日语言包），登录方式与官方一致。
所有流量直连你自己的 NAS，账号凭据只保存在本机。

## 功能特性

- 三种同步模式：双向同步 / 仅上传 / 仅下载
- 文件变动实时同步（本地监听，秒级触发），目录过滤规则 + 选择性同步
- 冲突保护：双向模式传播删除并保留修改冲突副本；单向模式删除源端时保留目标端副本
- 任务暂停 / 继续，断网自动恢复，全局上传/下载限速
- 系统托盘常驻，开机自启动（可开关）
- 同步日志：按数量/天数自动清理，可导出 gzip 归档
- **按需同步（Linux 上首次支持）**：用 FUSE3 复刻官方"文件按需同步"——
  文件只占位不占磁盘，打开时下载，右键可释放本地副本；缓存 LRU 淘汰；
  崩溃后重启会自动回收残留挂载
- **文件管理器集成**：
  - 麒麟 Peony：文件/文件夹右键「飞牛同步」菜单，文件状态角标（灰云未下载、
    绿云已下载、蓝下载中、上箭头上传中、橙已修改），状态变化自动刷新
  - UOS DDE：右键「飞牛同步」子菜单 + 同样的状态角标与自动刷新

## 安装

```bash
sudo dpkg -i xinchuang_fn-sync-client_0.2.3_arm64.deb   # 麒麟 arm64
sudo dpkg -i xinchuang_fn-sync-client_0.2.3_amd64.deb   # UOS x86_64

# 免安装（AppImage）：依赖系统自带的 webkit2gtk-4.0 / fuse
chmod +x xinchuang_fn-sync-client-0.2.3-x86_64.AppImage
./xinchuang_fn-sync-client-0.2.3-x86_64.AppImage
# 系统没有 FUSE 时可解包运行：
./xinchuang_fn-sync-client-0.2.3-x86_64.AppImage --appimage-extract-and-run
```

AppImage 不向系统目录写文件，因此**没有右键菜单和文件状态角标**（这两个由 deb 里的
文件管理器插件提供）；同步、托盘、按需同步功能与 deb 版一致。

运行时依赖都是国产化桌面的预装组件（webkit2gtk-4.0 / gtk3 / soup2 / appindicator /
fuse），离线 `dpkg -i` 即可，无需联网补依赖。

**装完请重启一次文件管理器（或重新登录桌面）**，右键菜单和角标才会出现：

- 麒麟：关闭并重新打开文件管理器窗口，或注销重登
- UOS：结束 `dde-file-manager -d` 进程后重新打开文件管理器
  （注意 Linux 进程名只保留前 15 个字符，`pkill -x dde-file-manager` 匹配不到）

按需同步创建任务时，电脑端目录必须是空文件夹（与官方 macOS 的 CloudStorage
目录语义一致），挂载后目录内容由 NAS 实时提供。

## 已知限制

- 只提供 deb；rpm / AppImage 暂未提供
- 客户端内"检查更新"未接入，更新请关注本帖
- FN Connect（fnid）远程连接未完整实现，建议用局域网或公网地址直连
- 按需同步依赖内核 fuse + `fuse3` 或 `fuse`（deb 已声明依赖）；麒麟 134 等只有
  fuse2 的机器会自动回退 `fusermount`
- 文件管理器插件按 Qt 5.12 构建（兼容 Qt 5.12–5.15 的麒麟批次）；更老的麒麟
  （Qt 5.11 及以下）暂未适配
- 桌面图标右键、拖拽等场景未覆盖，插件只接管文件管理器窗口内的右键与角标
